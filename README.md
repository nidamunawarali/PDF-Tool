# PDF-Tool

A simple web-based PDF Merger Tool built using Node.js and Express.js.

## Features

- Upload two PDF files
- Merge PDF files into a single PDF
- Simple and user-friendly interface
- View the merged PDF

## Technologies Used

- HTML
- CSS
- Bootstrap 4
- JavaScript
- Node.js
- Express.js
- Multer
- pdf-merger-js

## Project Structure

PDF-Tool/
├── public/
├── templates/
│   └── index.html
├── merge.js
├── server.js
├── package.json
└── package-lock.json

## How to Run

Install the required dependencies:

    npm install

Start the server:

    node server.js

Open the application in your browser:

    http://localhost:3000
